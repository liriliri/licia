## isStr

Check if value is a string primitive.

<details>
<summary>Type Definition</summary>

```typescript
function isStr(val: any): val is string;
```

</details>

|Name  |Desc                               |
|------|-----------------------------------|
|val   |Value to check                     |
|return|True if value is a string primitive|

```javascript
isStr('licia'); // -> true
```
