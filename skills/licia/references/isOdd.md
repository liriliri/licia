## isOdd

Check if number is odd.

<details>
<summary>Type Definition</summary>

```typescript
function isOdd(num: number): boolean;
```

</details>

|Name  |Desc                 |
|------|---------------------|
|num   |Number to check      |
|return|True if number is odd|

```javascript
isOdd(0); // -> false
isOdd(1); // -> true
isOdd(2); // -> false
```
