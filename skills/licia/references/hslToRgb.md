## hslToRgb

Convert hsl to rgb.

<details>
<summary>Type Definition</summary>

```typescript
function hslToRgb(hsl: number[]): number[];
```

</details>

|Name  |Desc      |
|------|----------|
|hsl   |Hsl values|
|return|Rgb values|

```javascript
hslToRgb([165, 59, 50, 0.8]); // -> [52, 203, 165, 0.8]
```
