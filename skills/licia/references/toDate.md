## toDate

Convert value to a Date.

<details>
<summary>Type Definition</summary>

```typescript
function toDate(val: any): Date;
```

</details>

|Name  |Desc            |
|------|----------------|
|val   |Value to convert|
|return|Converted Date  |

```javascript
toDate('20180501');
toDate('2018-05-01');
toDate(1525107450849);
```
