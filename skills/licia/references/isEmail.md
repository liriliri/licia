## isEmail

Loosely validate an email address.

<details>
<summary>Type Definition</summary>

```typescript
function isEmail(val: string): boolean;
```

</details>

|Name  |Desc                                 |
|------|-------------------------------------|
|val   |Value to check                       |
|return|True if value is an email like string|

```javascript
isEmail('surunzi@foxmail.com'); // -> true
```
