## last

Get the last element of array.

<details>
<summary>Type Definition</summary>

```typescript
function last(arr: any[]): any;
```

</details>

|Name  |Desc                     |
|------|-------------------------|
|arr   |The array to query       |
|return|The last element of array|

```javascript
last([1, 2]); // -> 2
```
