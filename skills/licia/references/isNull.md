## isNull

Check if value is an Null.

<details>
<summary>Type Definition</summary>

```typescript
function isNull(val: any): val is null;
```

</details>

|Name  |Desc                    |
|------|------------------------|
|val   |Value to check          |
|return|True if value is an Null|

```javascript
isNull(null); // -> true
```
