## shuffle

Randomize the order of the elements in a given array.

<details>
<summary>Type Definition</summary>

```typescript
function shuffle(arr: any[]): any[];
```

</details>

|Name  |Desc              |
|------|------------------|
|arr   |Array to randomize|
|return|Randomized Array  |

```javascript
shuffle([1, 2, 3]); // -> [3, 1, 2]
```
