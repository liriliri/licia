## longest

Get the longest item in an array.

<details>
<summary>Type Definition</summary>

```typescript
function longest(arr: string[]): string;
```

</details>

|Name  |Desc            |
|------|----------------|
|arr   |Array to inspect|
|return|Longest item    |

```javascript
longest(['a', 'abcde', 'abc']); // -> 'abcde'
```
