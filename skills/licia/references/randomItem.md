## randomItem

Get a random item from an array.

<details>
<summary>Type Definition</summary>

```typescript
function randomItem(arr: any[]): any;
```

</details>

|Name  |Desc                |
|------|--------------------|
|arr   |Array to get        |
|return|Randomly picked item|

```javascript
randomItem([1, 2, 3]); // -> 2
```
