## ordinal

Add ordinal indicator to number.

<details>
<summary>Type Definition</summary>

```typescript
function ordinal(num: number): string;
```

</details>

|Name  |Desc                   |
|------|-----------------------|
|num   |Number to add indicator|
|return|Result ordinal number  |

```javascript
ordinal(1); // -> '1st'
ordinal(2); // -> '2nd'
```
