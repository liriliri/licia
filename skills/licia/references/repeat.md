## repeat

Repeat string n-times.

<details>
<summary>Type Definition</summary>

```typescript
function repeat(str: string, n: number): string;
```

</details>

|Name  |Desc            |
|------|----------------|
|str   |String to repeat|
|n     |Repeat times    |
|return|Repeated string |

```javascript
repeat('a', 3); // -> 'aaa'
repeat('ab', 2); // -> 'abab'
repeat('*', 0); // -> ''
```
