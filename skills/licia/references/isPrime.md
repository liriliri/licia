## isPrime

Check if the provided integer is a prime number.

<details>
<summary>Type Definition</summary>

```typescript
function isPrime(num: number): boolean;
```

</details>

|Name  |Desc                            |
|------|--------------------------------|
|num   |Number to check                 |
|return|True if number is a prime number|

```javascript
isPrime(11); // -> true
isPrime(8); // -> false
```
