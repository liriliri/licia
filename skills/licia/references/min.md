## min

Get minimum value of given numbers.

<details>
<summary>Type Definition</summary>

```typescript
function min(...num: number[]): number;
```

</details>

|Name  |Desc                |
|------|--------------------|
|...num|Numbers to calculate|
|return|Minimum value       |

```javascript
min(2.3, 1, 4.5, 2); // 1
```
