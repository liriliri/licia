## isEven

Check if number is even.

<details>
<summary>Type Definition</summary>

```typescript
function isEven(num: number): boolean;
```

</details>

|Name  |Desc                  |
|------|----------------------|
|num   |Number to check       |
|return|True if number is even|

```javascript
isEven(0); // -> true
isEven(1); // -> false
isEven(2); // -> true
```
