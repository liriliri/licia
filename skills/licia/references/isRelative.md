## isRelative

Check if path appears to be relative.

<details>
<summary>Type Definition</summary>

```typescript
function isRelative(path: string): boolean;
```

</details>

|Name  |Desc                               |
|------|-----------------------------------|
|path  |Path to check                      |
|return|True if path appears to be relative|

```javascript
isRelative('README.md'); // -> true
```
