## isLeapYear

Check if a year is a leap year.

<details>
<summary>Type Definition</summary>

```typescript
function isLeapYear(year: number): boolean;
```

</details>

|Name  |Desc                       |
|------|---------------------------|
|year  |Year to check              |
|return|True if year is a leap year|

```javascript
isLeapYear(2000); // -> true
isLeapYear(2002); // -> false
```
