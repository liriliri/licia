## reverse

Reverse array without mutating it.

<details>
<summary>Type Definition</summary>

```typescript
function reverse(arr: any[]): any[];
```

</details>

|Name  |Desc           |
|------|---------------|
|arr   |Array to modify|
|return|Reversed array |

```javascript
reverse([1, 2, 3]); // -> [3, 2, 1]
```
