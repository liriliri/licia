## max

Get maximum value of given numbers.

<details>
<summary>Type Definition</summary>

```typescript
function max(...num: number[]): number;
```

</details>

|Name  |Desc                |
|------|--------------------|
|...num|Numbers to calculate|
|return|Maximum value       |

```javascript
max(2.3, 1, 4.5, 2); // 4.5
```
