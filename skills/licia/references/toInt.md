## toInt

Convert value to an integer.

<details>
<summary>Type Definition</summary>

```typescript
function toInt(val: any): number;
```

</details>

|Name  |Desc             |
|------|-----------------|
|val   |Value to convert |
|return|Converted integer|

```javascript
toInt(1.1); // -> 1
toInt(undefined); // -> 0
```
