## swap

Swap two items in an array.

<details>
<summary>Type Definition</summary>

```typescript
function swap(arr: any[], a: number, b: number): any[];
```

</details>

|Name  |Desc         |
|------|-------------|
|arr   |Array to swap|
|a     |First index  |
|b     |Second index |
|return|Array given  |

```javascript
const arr = [1, 2];
swap(arr, 0, 1); // -> [2, 1]
```
