## rgbToHsl

Convert rgb to hsl.

<details>
<summary>Type Definition</summary>

```typescript
function rgbToHsl(rgb: number[]): number[];
```

</details>

|Name  |Desc      |
|------|----------|
|rgb   |Rgb values|
|return|Hsl values|

```javascript
rgbToHsl([52, 203, 165, 0.8]); // -> [165, 59, 50, 0.8]
```
